## 1. The Pitch (in one paragraph)

PharmaWatch is Pakistan's first **agentic AI consumer protection system** for the pharmaceutical sector. A user reports being overcharged at a pharmacy; the agent autonomously plans an investigation, queries the official DRAP database for the legal MRP, finds cheaper generic alternatives with the same active ingredient, cross-checks against DRAP's spurious-medicine alerts, **pulls the pharmacy's prior enforcement history with notice references and penalty amounts**, anonymously logs the report to a real-time community heatmap, and generates a pre-filled formal complaint letter to DRAP. Built on DRAP's own public data — using it against the bad actors it was designed to catch.

**Differentiator:** Dawaai.pk tells you what a medicine *should* cost. PharmaWatch *proves* you were defrauded, with citations.

## 3. Final Tech Stack

### Backend
- **FastAPI** + Uvicorn — async, SSE-friendly for trace streaming
- **google-generativeai** SDK — `gemini-2.5-flash` for agent loop (optionally `gemini-2.5-pro` for final synthesis)
- **SQLite** (`drap.sqlite`) — local Golden Source: medicines, generics, spurious_alerts, **local_drap_enforcement**
- **firebase-admin** — Firestore for community reports + heatmap real-time
- **httpx + BeautifulSoup4** — DRAP scraper (one-shot CLI)
- **ReportLab** — server-side PDF generation
- **pydantic v2** — DTOs and config

### Frontend
- React 18 + Vite
- Tailwind CSS
- `react-leaflet` or Google Maps JS API — fraud heatmap
- Server-Sent Events for live agent trace panel
- Firebase JS SDK — real-time heatmap subscription

### Infrastructure (hackathon)
- Local dev only — no deployment required for demo
- Firebase project (free tier)
- Pre-scraped SQLite committed to repo (or generated by `scripts/scrape_drap.py`)

## 4. Architecture — 3-Tier Modular Monolith

```
[ React FE ]
     │
     ▼  HTTP + SSE
┌────────────────────────────────────────┐
│  TIER 1 — Presentation (api/routes/)   │   ← FastAPI routers, Pydantic schemas
└────────────────────────────────────────┘
     │
     ▼
┌────────────────────────────────────────┐
│  TIER 2 — Application (agent/, services/) │   ← Gemini orchestrator, tool registry,
│                                        │       business rules. NO HTTP, NO SQL.
└────────────────────────────────────────┘
     │
     ▼
┌────────────────────────────────────────┐
│  TIER 3 — Data (data/)                 │   ← SQLite repos, Firestore client,
│                                        │       external API wrappers
└────────────────────────────────────────┘
```

**Hard rule:** dependencies point only downward. `data/` never imports from `agent/`. `agent/` never imports from `api/`.

## 6. Database Schemas

### 6.1 SQLite — `drap.sqlite`

#### `medicines`
```sql
CREATE TABLE medicines (
    reg_number          TEXT PRIMARY KEY,
    brand_name          TEXT NOT NULL,
    generic_name        TEXT,
    active_ingredient   TEXT NOT NULL,
    strength            TEXT NOT NULL,
    mrp_pkr             INTEGER NOT NULL,
    manufacturer        TEXT,
    last_updated        TIMESTAMP NOT NULL
);
CREATE INDEX idx_med_brand ON medicines(brand_name);
CREATE INDEX idx_med_ingredient ON medicines(active_ingredient, strength);
```

#### `spurious_alerts`
```sql
CREATE TABLE spurious_alerts (
    alert_id            INTEGER PRIMARY KEY AUTOINCREMENT,
    medicine_name       TEXT NOT NULL,
    batch_number        TEXT,
    reason              TEXT NOT NULL,         -- 'counterfeit'|'substandard'|'mislabeled'
    alert_date          DATE NOT NULL,
    drap_notice_ref     TEXT NOT NULL,
    source_url          TEXT
);
CREATE INDEX idx_spurious_med ON spurious_alerts(medicine_name);
```

#### `local_drap_enforcement` ⭐ (the "Undeniable Investigation" table)
```sql
CREATE TABLE local_drap_enforcement (
    -- Identity
    violation_id        INTEGER PRIMARY KEY AUTOINCREMENT,
    pharmacy_id         TEXT NOT NULL,         -- slug: "city-pharmacy-saddar-karachi"
    pharmacy_name       TEXT NOT NULL,
    pharmacy_license_no TEXT,
    city                TEXT NOT NULL,
    area                TEXT,
    address             TEXT,

    -- Violation
    violation_type      TEXT NOT NULL,         -- 'overcharging'|'counterfeit_sale'|
                                               -- 'expired_stock'|'unlicensed_operation'|
                                               -- 'spurious_medicine'|'narcotic_violation'|
                                               -- 'illegal_import'|'storage_violation'
    violation_date      DATE NOT NULL,
    medicine_involved   TEXT,                  -- nullable
    description         TEXT NOT NULL,

    -- Penalty (the "undeniable" part)
    penalty_type        TEXT,                  -- 'fine'|'license_suspended'|
                                               -- 'license_cancelled'|'warning'|
                                               -- 'stock_seized'|'criminal_referral'
    penalty_amount_pkr  INTEGER,
    suspension_days     INTEGER,

    -- Evidence chain
    drap_notice_ref     TEXT,                  -- e.g. "DRAP/ENF/2024/1284"
    source_url          TEXT NOT NULL,
    source_type         TEXT NOT NULL,         -- 'drap_official'|'news_dawn'|'news_geo'|'news_tribune'
    issuing_authority   TEXT,

    -- Computed / metadata
    severity            TEXT NOT NULL,         -- 'low'|'medium'|'high'|'critical'
    is_resolved         BOOLEAN DEFAULT FALSE,
    scraped_at          TIMESTAMP NOT NULL,
    last_verified_at    TIMESTAMP NOT NULL
);

CREATE INDEX idx_enf_pharmacy_id    ON local_drap_enforcement(pharmacy_id);
CREATE INDEX idx_enf_pharmacy_city  ON local_drap_enforcement(pharmacy_name, city);
CREATE INDEX idx_enf_violation_date ON local_drap_enforcement(violation_date DESC);
CREATE INDEX idx_enf_severity       ON local_drap_enforcement(severity);
```

**Severity rules (computed at scrape time):**
- `critical` — counterfeit_sale, license_cancelled, criminal_referral
- `high` — fine ≥ Rs. 100,000, license_suspended ≥ 30 days, spurious_medicine
- `medium` — fine Rs. 25,000–100,000, suspension < 30 days
- `low` — warning, minor procedural

### 6.2 Firestore — `community_reports` collection

```js
// One document per report — anonymous by design
{
  pharmacyName:   string,    // as entered
  pharmacyId:     string,    // slug for joins
  area:           string,
  city:           string,
  medicine:       string,
  officialMRP:    number,
  chargedPrice:   number,
  overchargeAmt:  number,
  overchargePct:  number,
  timestamp:      Timestamp,
  sessionHash:    string     // one-way hash, rate-limit only — NOT identifying
}
```

**Privacy invariant:** zero PII fields. `sessionHash` cannot be reversed to identify a user.

## 7. The 8 Agent Tools (revised from SRS's 9)

| Tool | Tier | Purpose | Notes |
|---|---|---|---|
| `drap_price_lookup` | data/drap | Official MRP + active ingredient | Local SQLite, retries on miss |
| `generic_alternatives` | data/drap | Same active ingredient, cheaper brands | Local SQLite |
| `spurious_alert_check` | data/drap | DRAP counterfeit/substandard alerts | Local SQLite |
| **`drap_enforcement_lookup`** ⭐ | data/drap | **Pharmacy's prior enforcement history** | The Investigation Report data source |
| `log_community_report` | data/firebase | Anonymous report logging | Firestore write |
| `get_pharmacy_reports` | data/firebase | Aggregated community reports for a pharmacy | Firestore read + 30-day window |
| `web_search_fallback` | external | LAST RESORT — recent news only | Forbidden for MRP lookups via prompt |
| `generate_complaint_letter` | services | Build PDF complaint with all evidence | ReportLab |

(`generate_collective_dossier` exists as a service function but is invoked manually for the demo, not via tool call.)

   - `drap_price_lookup` → MRP Rs. 640 ✓
   - `generic_alternatives` → 3 found, cheapest Rs. 390 ✓

   - Cheaper alternative: Cefim Rs. 390 — saves Rs. 810
5. **2:15 — Click "Download Collective Complaint."** PDF generates instantly with all 14 reports cited. Formal letter to DRAP Islamabad.
6. **2:45 — Map updates in real time.** Saddar pharmacy now shows 14 reports.
7. **2:55 — Closing line:** *"That is not a price checker. That is justice infrastructure."*

## 10. Risks & Mitigations

| Risk | Likelihood | Mitigation |
|---|---|---|
| Gemini rate limits during demo | Medium | Pre-warm with the demo query; have screen recording fallback |
| Scrape fails / drap.gov.pk schema change | Low | Fixtures committed; demo never hits live DRAP |
| Firebase real-time sync lag | Low | Pre-seed; don't rely on cold writes during demo |
| Gemini hallucinates an MRP | Medium | System prompt forbids generating prices; only synthesizes from tool outputs. ALL prices come from SQLite. |
| Trace panel UI doesn't render in time | Medium | Build it FIRST in afternoon — it's the agentic-behavior proof |
| Scope creep | High | Anything not in this doc gets a "Phase 2" sticker |
